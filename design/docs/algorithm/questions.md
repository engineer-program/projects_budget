# Вопросы по новому техническому заданию

1. Помимо заработных плат как будем учитывать дополнительные заработные платы, отпускные, больничные?
2. Если будем учитывать больничные/отпускные, то как рассчитывать реальные больничные/отпускные человека и вводить их в программу? 'Решение' - возможно автоматический импорт из R-MES или 1С.
3. Помимо премий сотрудников как будем учитывать дополнительные премии (премии 2)? Решение - добавить столбец рядом с премиями сотрудников и заполнять сразу оба столбца за выбранный квартал.
4. Карточка проекта - какую информацию по проекту мы конкретно хотим видеть? Необходимо разработать эскиз с конкретными полями. Предложение. Поля из Easy Redmine:

* имя проекта,
* наименование в санде,
* наименование в 1С,
* номер проекта,
* ведущий отдел,
* руководитель проекта.

Поля дополнительные:

* дата начала проекта,
* стартовый бюджет,
* остаток бюджета на данный момент.

5. На странице "Отчёт за период по проектам" столбцы расходов на З/П - как учитывать наличие больничных/отпускных в конкретном месяце, как их вычислять или автоматически вытягивать из других систем?
